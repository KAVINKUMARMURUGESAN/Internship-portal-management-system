# Internship Portal Management System

## Overview

The Internship Portal Management System is a web-based application developed to manage students, internships, and internship applications through a centralized platform.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Maven

## Modules

### Student Module
- Student registration and login
- View available internships
- Apply for internships
- Track application status
- Manage profile

### Internship Module
- View internship details
- Browse available internships
- Apply for internships

### Application Module
- Submit internship applications
- Track application status

### Admin Module
- Admin login
- Add internships
- Manage internships
- View students
- Manage applications

## Architecture

Frontend → Spring Boot → Spring Data JPA → PostgreSQL

## Database

The project uses PostgreSQL as the database.

Database name:

`internship_portal`

## How to Run

1. Clone the repository.
2. Create the PostgreSQL database.
3. Configure the database credentials in `application.properties`.
4. Install Maven dependencies.
5. Run the Spring Boot application.
6. Open the application in your browser.
